# سامانه سالن مطالعه آل یاسین

## اجرای محلی
نیازمند Python 3.10+ است.
1. پوشه را از ZIP خارج کنید.
2. در ترمینال همین پوشه اجرا کنید: `pip install -r requirements.txt`
3. رمز مدیر و کلید نشست را تنظیم کنید:
   - Linux/macOS: `export ADMIN_PASSWORD='رمز-قوی-جدید'` و `export SESSION_SECRET='یک-رشته-تصادفی-طولانی'`
   - Windows PowerShell: `$env:ADMIN_PASSWORD='رمز-قوی-جدید'` و `$env:SESSION_SECRET='یک-رشته-تصادفی-طولانی'`
4. اجرا: `python app.py`
5. در مرورگر باز کنید: `http://127.0.0.1:5000`

## انتشار در اینترنت با Render
**توجه:** نسخه فعلی اطلاعات را در SQLite نگه می‌دارد. فضای دیسک سرویس رایگان Render موقتی است؛ با راه‌اندازی مجدد یا انتشار نسخه جدید ممکن است اطلاعات از بین برود. برای استفاده واقعی، باید دیسک دائمی در پلن پشتیبان آن فعال کنید یا برنامه به PostgreSQL منتقل شود. راهنمای محدودیت‌ها: https://render.com/docs/free

1. در GitHub حساب بسازید و یک مخزن (Repository) جدید ایجاد کنید.
2. فایل‌های داخل این پوشه را در مخزن آپلود کنید؛ فایل ZIP را به‌تنهایی آپلود نکنید، اول آن را از حالت فشرده خارج کنید.
3. در https://render.com ثبت‌نام کنید و GitHub را متصل کنید.
4. در داشبورد Render روی **New + → Web Service** بزنید و مخزن را انتخاب کنید.
5. این تنظیمات را وارد کنید:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
6. در بخش **Environment** این متغیرها را اضافه کنید:
   - `ADMIN_PASSWORD` = یک رمز قوی و تازه
   - `SESSION_SECRET` = یک رشته تصادفی طولانی (حداقل ۳۲ بایت)
   - `COOKIE_SECURE` = `1`
7. برای ذخیره ماندگار اطلاعات SQLite، در سرویس/پلن سازگار یک Persistent Disk اضافه کنید و مسیر Mount را `/var/data` قرار دهید. سپس متغیر `DATA_DIR=/var/data` را اضافه کنید. نسخه حاضر این مسیر را برای ذخیره پایگاه داده پشتیبانی می‌کند. گزینه دیگر، انتقال برنامه به PostgreSQL است.
8. روی **Create Web Service** کلیک کنید. پس از پایان Deploy، Render یک نشانی شبیه `https://نام-سایت.onrender.com` می‌دهد.
9. نشانی را با گوشی باز کنید و میز/کمد/برق را امتحان کنید.

## نکات امنیتی
- رمز فرستاده‌شده در چت در فایل‌ها قرار داده نشده؛ اگر رمز واقعی بوده، بهتر است آن را عوض کنید.
- نام استفاده‌کنندگان کمدها در نمای عمومی نمایش داده نمی‌شود.
- تا وقتی ذخیره‌سازی پایدار را تنظیم نکرده‌اید، اطلاعات مهم را فقط در این نسخه آنلاین وارد نکنید.
- سرویس رایگان Render پس از ۱۵ دقیقه بی‌ترافیکی متوقف می‌شود و اولین بازدید بعدی ممکن است حدود یک دقیقه طول بکشد.
